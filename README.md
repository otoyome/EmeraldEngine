過去に作ったゲーム用のフレームワークを元に、レンダリング周りやエンジンの仕組みを最適化しつつ作りました。  

〇エンジン回り  
・自作数学ライブラリー  
　数学単体の勉強及び、SIMDの勉強のために自作  
・当たり判定ライブラリー  
　勉強のために自作  
　一部OBB類やカプセルキャスト等の計算はAIを使用  
・継承ベースのオブジェクト管理  
　学生が猫も杓子もECS等を実装していたので、  
　こういうやり方もあるよと提示するためにしました。

〇レンダリング周り  
・DirectX11、C++,HLSL使用  
・モデルデータはメッシュレットによる描画  
・階層型オクルージョン/フラスタム/メッシュレットカリングによる効率的なメッシュ描画  
・シェーダーホットリロードを用いたシェーダーの構築処理  
・描画タイミング/描画物毎に制約はあるが、ある程度自由なマテリアルの構築システム（UEを参考）  
・シェーディング処理の効率化のため、ディファードレンダリング・クラスタードライティングの実装。  
・物理シェーディングを正しく実装して行くため、  
　ライトは測光量で取り扱い、レンダリングは放射量をベースに取り扱っている。  
　また、描画色域はRec2020のリニア空間でレンダリングしている。  
・↑の対応のためAPEX基準の露光調整を行うようにしている。  
　また、HDRモニターを基準としているのでディスプレイに応じて色域・伝導関数を変えている  
・MHWの資料を参考にした自由に様々なアイテムを追加して行けるコンピュートパーティクルシステム  
・相対座標レンダリングに対応
